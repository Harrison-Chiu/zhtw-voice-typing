# experiments/

一次性的實驗腳本。每支腳本回答一個特定問題，跑完把結論寫進
`CLAUDE.md` 的「已確立的設計決策」或 `docs/` 的專題規格，腳本本身留著供重現。

## `experiments/results/` 不在版本控制中

實驗的原始輸出（JSON / log / HTML 檢視器）寫在 `experiments/results/`，
該目錄已列入 `.gitignore`。

原因：那些檔案存的是作者本人語音的**逐字稿**——測試音檔是實際錄下的會議與口述內容，
單一實驗檔就可能含數千段轉錄文字。腳本可公開，語料不行。

因此 `CLAUDE.md` 與 `docs/` 中引用的 `experiments/results/*.json` 路徑，
在作者的本機 checkout 存在，在 clone 出來的副本不存在。引用保留是為了讓作者能追溯依據；
對其他讀者而言，各項結論的實驗設計、樣本數與邊界條件都寫在引用它的那段文字裡。

重跑任一實驗會在本機重新產生對應的結果檔。多數腳本需要 `data/test_audio/` 下的音檔，
那些音檔同樣不在版本控制中。
