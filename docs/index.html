設計原則

  • 模組化 — 每個模組有統一的抽象介面，可以獨立替換（例如換 ASR 引擎不用動其他程式碼）
  • Pipeline 模式 — 文字後處理可串接多個步驟，順序執行
  • Config 驅動 — 所有設定集中在 config.yaml，不用改程式碼

模組說明

Audio Capture

使用 sounddevice 從麥克風即時收音，16kHz 取樣率。

抽象介面 AudioSource 支援未來擴展（檔案輸入、串流等）。

ASR Engine

目前使用 Qwen3-ASR-1.7B，佔用約 3.9GB VRAM。

抽象介面 ASREngine，可替換為 SenseVoice、Whisper 等。

Text Processing

OpenCC s2twp：簡體→台灣繁體 + 慣用詞轉換。

TW Terms：自訂詞表補充 OpenCC 沒覆蓋的台灣用語。

Output

目前：辨識結果複製到系統剪貼簿。

未來可擴展：模擬鍵盤輸入、API 輸出等。

工具鏈

uv

Rust 寫的 Python 套件管理工具。取代 pip + venv，速度快 10-100 倍，自動管理虛擬環境和鎖檔。

uv add 套件名      # 安裝
uv sync          # 同步環境
uv run python    # 在 venv 中執行
ruff

Rust 寫的 Python linter + formatter。取代 black + flake8 + isort，毫秒級速度。

uv run ruff check .     # 檢查
uv run ruff format .    # 格式化

操作說明

啟動

cd D:\Harrison\code_test\asr-input
uv run python -m asr_input.main

操作流程

1️⃣程式啟動，載入模型（首次約 15 秒，之後有快取更快）
2️⃣按 Enter → 開始錄音 🎤
3️⃣講完話 → 再按 Enter 停止錄音
4️⃣等待辨識（通常 1-3 秒）
5️⃣結果自動轉為台灣繁中 → 複製到剪貼簿 📋
🔁重複步驟 2-5，或輸入 q + Enter 退出

測試音檔（不用麥克風）

uv run python test_audio_file.py

會對 data/test_audio/ 裡的 .m4a 檔逐個辨識。

設定檔 (config.yaml)

asr:
  engine: qwen
  model_id: "Qwen/Qwen3-ASR-1.7B"
  device: cuda
  language: "Chinese"
  prompt: "以下是台灣繁體中文的語音轉錄。"

audio:
  sample_rate: 16000

processing:
  opencc_config: s2twp
  tw_dict_path: data/tw_dict.yaml

output:
  method: clipboard

繁中轉換流程

ASR 模型輸出的中文通常是簡體 + 中國用語，需要兩層後處理：

第一層：OpenCC s2twp

Open Chinese Convert — 開源中文繁簡轉換工具。s2twp 模式 = 簡體 → 台灣繁體 + 慣用詞轉換。

ASR 原始輸出OpenCC 轉換後
我今天下载了一个软件→我今天下載了一個軟體
这个视频的默认设置→這個影片的預設設定
需要激活插件→需要啟用外掛
请打印并上传到博客→請列印並上傳到部落格

第二層：自訂台灣用語詞表

補充 OpenCC 沒涵蓋到的替換，定義在 data/tw_dict.yaml：

中國用語台灣用語
人工智能→人工智慧
代碼→程式碼
調用→呼叫
交互→互動
字節→位元組

可以隨時編輯 data/tw_dict.yaml 新增替換規則。

Prompt 引導（第零層）

在 ASR 推理時注入提示："以下是台灣繁體中文的語音轉錄。"

這是「軟性引導」，模型不一定會遵守，所以主要靠後面兩層處理確保品質。

後續計畫

已完成

v0.1 — 專案初始化 + 基礎 Pipeline

Git + uv + ruff 工具鏈、模組化骨架、Qwen3-ASR 整合、OpenCC + 台灣詞表後處理、CLI 介面、音檔測試驗證

下一步

v0.2 — VAD 切段 + 速度優化

加入語音活動偵測（VAD），將長音訊切成短段逐段辨識。解決長音檔辨識變慢的問題，也為即時串流鋪路。可考慮 Silero VAD（輕量、準確）。

下一步

v0.3 — 全域快捷鍵 + System Tray

不用開終端機，按全域快捷鍵（例如 Ctrl+Shift+Space）直接開始/停止錄音。程式縮在系統匣常駐，辨識結果直接貼到游標位置或剪貼簿。

未來

v0.4 — 即時串流辨識

邊講邊出字，不用等錄完。需要 ASR 引擎支援 streaming mode（Paraformer 或 sherpa-onnx），或用 VAD 切段 + 快速推理模擬即時效果。

未來

v0.5 — 多引擎支援

實作 SenseVoice、Whisper 引擎，可在 config.yaml 切換。不同場景選不同引擎（速度 vs 品質）。

未來

v0.6 — Web UI 測試介面

瀏覽器介面，用於測試/展示/設定調整。可以上傳音檔測試、即時預覽轉換結果、編輯詞表。不取代日常使用的快捷鍵模式。

未來

探索 — 詞表 + 品質改善

擴充台灣用語詞表、加入領域專用詞（技術/醫療/法律）、用 LLM 做最後一道潤稿、處理「平臺→平台」這類 OpenCC 過度轉換的問題。
